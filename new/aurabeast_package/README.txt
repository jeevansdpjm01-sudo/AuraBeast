AuraBeast — Music Streaming App Prototype
==========================================

HOW TO RUN
1. Unzip this folder.
2. Double-click index.html (or open it in any modern browser: Chrome, Safari, Edge, Firefox).
3. No install or server needed — it runs entirely client-side.

WHAT'S INSIDE
- index.html — the full app (splash screen, onboarding, home dashboard,
  full-screen music player with audio-reactive visualizer, search,
  library, playlists, artist pages, and the AI Auto-Fix system).

NOTES
- Audio playback uses free demo tracks (SoundHelix) streamed from the web —
  an internet connection is needed to hear playback and load cover art.
- This is a front-end prototype/demo build, not connected to a real backend,
  so likes/playlists/follows reset if you reload the page.
